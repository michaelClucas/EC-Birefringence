# arXiv:2512.21888 - Shao, Obata, Zhang, "Implications of Cosmic Birefringence for Multi-Field ALP Dark Matter"

Version read: v2 (13 Oct 2026), full text via arxiv.org/html/2512.21888. Preprint KEK-TH-2790. Theory paper; no new data analysis.

## Data used as input
- beta = 0.215 +- 0.074 deg from ACT DR6 (Diego-Palazuelos & Komatsu, arXiv:2509.13654) (Sec. 1, Eq. 5, Fig. 1-2 captions).
- beta = 0.34 +- 0.09 deg from Planck HFI+LFI+WMAP with filamentary dust EB model and free calibration angles (Eskilt & Komatsu, arXiv:2205.13962) (Sec. 1, Sec. 3.2). Rounded form of 0.342 +0.094 -0.091.
- Washout bound: 1 - J0(g phi_*) <~ 5.8e-3 (95%) from a Planck-based simulation in Fedderke, Graham & Rajendran 2019 (Phys. Rev. D 100, 015040) (Eq. 11). arXiv ID not given in the citing reference list.
- Local oscillation: SPT-3G limits the induced rotation amplitude to < 0.071 deg (95%) (Ferguson et al. arXiv:2203.16567) (footnote 1).
- Local DM density rho_0dm ~= 0.4 GeV/cm3; ALP fraction f_phi = 0.01 assumed (Winch et al. 2024 bound cited) (Sec. 2, 3.2).
- Mentions POLARBEAR Crab Nebula analysis (arXiv:2403.02096) as supporting a time-varying signal (Sec. 1).

## Model and conventions
- Action Eq. (1), verbatim in their notation:
  S = int d^4x sqrt(-g) ( -(1/2) nabla^mu phi nabla_mu phi - V(phi) - (1/4) F^{mu nu} F_{mu nu} - (1/4) g_{phi gamma} phi F_{mu nu} Ftilde^{mu nu} )
  Metric: FLRW ds^2 = -dt^2 + a^2 dx^2 (Sec. 2), so signature (-,+,+,+). Epsilon sign convention not stated.
- beta <-> Delta phi, Eq. (2): beta(nhat) = (1/2) g_{phi gamma} (phi(t0, 0) - phi(t_LSS, d_LSS nhat)) = betabar + delta beta(nhat). (The second line of Eq. 2 in the HTML has a misplaced bracket; the first line is unambiguous.)
- With phi_LSS ~ 0 (field oscillates many times during recombination), betabar = (1/2) g phi_obs ~= 0.215 deg (Eq. 5). So the signal here is set by the LOCAL field at the observer, not the LSS value.
- Two-field action Eq. (13): both fields couple with the same g_{phi gamma} to (phi^1 + phi^2) F Ftilde, quadratic potentials m_i^2 (phi^i)^2 / 2.
- Stokes convention Eq. (8): (Q +- iU) = eps I e^{+-2i(psi + g phi(t)/2)} <e^{-+ i g phi(t_LSS)}>. Sign statement on clockwise/counterclockwise: not given.

## Key results
- phi_0 ~= 2.5e12 GeV kappa^{1/2} (m/1e-24 eV)^{-1} (Eq. 4); 95% upper value of local amplitude 1.39 phi_0 (Rayleigh) (Sec. 2).
- Single field, required coupling (95%), Eq. (6): 2.16e-15 GeV^-1 (m/1e-24 eV) kappa^{-1/2} (beta/betabar) <~ g <~ 6.64e-15 GeV^-1 (...).
- Washout upper bound, Eq. (12): g <~ 9.6e-16 GeV^-1 (m/1e-24 eV) (f_phi Omega_DM h^2 / 0.11933)^{-1/2}. About 2x below the lower bound needed: single-field ALP explanation disfavoured in 1e-25 to 1e-22 eV (Sec. 2, Fig. 1).
- Two fields, random phases, Eq. (16): lower bound 2.16e-15 x (m1 m2 / sqrt(kappa1 m2^2 + kappa2 m1^2)) / 1e-24 eV x (beta/0.215 deg); upper bound printed as 6.64e-14 (one decade larger than the single-field 6.64e-15 in Eq. 6; possibly a typo in the paper, unverified).
- Two fields, phase-aligned, both at 95% amplitude, Eq. (17): g_min = 2 beta / (1.73 (phi_0^1 + phi_0^2)) = 1.72e-15 GeV^-1 (...)^{-1} (beta/0.215 deg).
- Two-field washout, Eq. (21)-(22): 1 - J0 J0 ~= (g^2/2)(f1/m1^2 + f2/m2^2) rho_*DM <~ 5.8e-3, giving the same 9.6e-16 coefficient with the two-mass combination.
- Conclusion: generic two-field superposition does not relax the washout tension; the fine-tuned phase-aligned case reduces the tension by about sqrt(2) and fits ACT within 1 sigma; with Planck+WMAP beta, compatible at 2 sigma only after allowing for local DM density uncertainty (Sec. 3.2, 4).

## Frequency dependence, alpha handling, anisotropy
- Not addressed (achromatic Chern-Simons rotation assumed; no alpha modelling since no data analysis). Anisotropic delta beta is mentioned as tightly constrained (citing BICEP, ACT, SPT, Planck), no numbers given.

## Caveats stated
- Depends on local DM density; phase alignment needs an unspecified mechanism (suggested V_int ~ rho_de cos(phi1 - phi2), EFT not built).
