# 20261120-014 data-reproduce-fit

The ACT DR6 β = 0.215° ± 0.074° (2509.13654) is 2.9σ with systematics caveats and may not be cosmological. Every mechanism here is a candidate mechanism.

## Question
1. Can `python -m src.reproduce` regenerate every number in the "predicted β" and "needed parameter vs bound" columns of CLAIMS.md from data/, by calling the work/ scripts that produced them?
2. How do the live axion-class candidates (EC-03', KK-02, generic ALP) fit the isotropic β likelihood (ACT DR6; ACT+WMAP+Planck) and SPT-3G A_CB, against the null β = 0?

## Method
**Claim numbers** (`src/claims_numbers.py`, `src/claims_expected.csv`).
- Expected values are kept in `src/claims_expected.csv`, not parsed out of CLAIMS.md. Each row stores the claim id, the text exactly as printed in CLAIMS.md, the number it stands for, and a rounding rule: `sig n` (same at n significant figures), `dec n` (same at n decimals), `oom` (same power of ten, for "~10¹²⁰"), `floor` (for "≥ 29"), `exact`. `compare()` also checks that the printed text still occurs in that claim's CLAIMS.md row, so an edit to CLAIMS.md that is not mirrored in the CSV is flagged as `(text not in CLAIMS.md)`.
- Numbers are regenerated by importing the work/ scripts and calling them. Only their stdout is parsed where they print and do not return. No formula is copied, except the 3-line unrounded recomputation of the EC-03' β_max from the arrays `variants.main` uses. The printed 0.136 is rounded, and the fits need the unrounded value.
  - EC-01: `007/common.Cosmo` (cosmology from `data/cosmo_inputs.csv`), |ξS₀| = 2β/∫dt from LSS to today. The 003 `estimates.py` gives the same 1.13×10⁻³⁵ eV, but it reads placeholder cosmology from `inputs.json`, so it is not used.
  - EC-02, EC-04, EC-05: `007/ec02_nogo.main`, `ec04_estimates.main`, `ec05_loop.main`.
  - EC-03: `008/variants.qcd_variants`.
  - EC-03': `008/beta_scan.main` (all 45 masses; `--fast-scan` uses the 17 masses in 10⁻³⁴-10⁻³⁰ eV, which gives the same maximum), then `variants.main`.
  - KK-02/03/04: `009/kk_bounds.main`.
  - Files these scripts write are redirected to `artifacts/reproduce/` by patching the module's `HERE`, so no committed file in another work folder is touched. Work folders share module names (`common.py`), so `claims_numbers.load()` drops modules from other work folders before each import.
- The regenerated 008 scan is compared with the committed `work/20261120-008.../scan.csv`.

**Fits** (`fit_candidates.py`, output `fit_results.csv`). β uses the `src.likelihood.IsotropicBeta` Gaussians: `act_dr6` 0.215 ± 0.074, and `act_wmap_planck` 0.264 ± 0.058, the published combination. SPT uses `SPTLite` (SPT-3G D1 BB lite, calibrated CB template, task 010), with χ²_SPT(A_CB) profiled over r ∈ [0,1] and A_LT ∈ [0,3].

| model | β range | prior for Savage-Dickey | A_CB range | k_eff | k_full (what counts) |
|---|---|---|---|---|---|
| null | 0 | | 0 | 0 | 0 |
| generic ALP | free | uniform β ∈ [-1°, 1°] (as in 010) | free ≥ 0 | 1 | 1 (β; g, m, φ_i enter only through β) |
| EC-03' cap c: an ALP with g = 8α/πf set by hand (skeptic 011) | \|β\| ≤ B(c) = 0.1364°·√(c/5%) | uniform φ_i ⇒ uniform β on [-B, B] | ≤ (H_inf,max g_T F/4π)² = 3.6×10⁻¹⁶ | 1 | 2 (φ_i, m on the plateau); the cap is fixed per row: 2.7% (Planck 2018 + BOSS) and 6.9% (Planck 2018), both 95% at m = 10⁻³² eV from `data/ultralight_fraction_bounds.csv` (2301.08361 Table 2, task 013); 5% (the 008 assumption); 12% (what 0.215° needs; above the Planck 2018 limit, labelled EXCL). No per-mass bound exists at 5-8×10⁻³³ eV |
| KK-02 k | \|β\| ≤ kα/2 (0.209°·k) | uniform Δϑ ∈ [-π, π] | ≤ (kα/2)² (θ randomised by O(π), 009 envelope) | 1 | 2 (Δϑ, timing/mass 2πLM); k is a discrete model label |

- B(c) ∝ √c holds while φ_i < πf/N_q. The script asserts this; at 12% φ_i = 1.45×10¹⁸ GeV against the cap of 2.08×10¹⁸ GeV.
- EC-03' A_CB: from 008 `anisotropy.py`, A_CB = (βR/F)²(H_inf/2πφ_i)²S_L with φ_i = 2β/(g_T F). On the plateau that gives (H_inf g_T F/4π)², independent of β and the cap. H_inf,max = 4.7×10¹³ GeV (BK18).
- Bounded best fits: the mean is clipped to ±B. The χ² paid at the bound is listed as "penalty", meaning χ²_min(model) − χ²_min(ALP).
- Significance uses Wilks with 1 dof. For bounded fits this is approximate (boundary).
- AIC is computed with k_eff and with k_full.
- BIC with n = 1 (one compressed β) has ln n = 0, so ΔBIC = Δχ², with no penalty. This is shown, not hidden. BIC with n = 6 (β + 5 SPT bandpowers) is the joint fit, using k_eff.
- Savage-Dickey B₁₀ is computed numerically for the nested null β = 0 and checked against the analytic Gaussian value (assert < 10⁻⁴).
- SPT: Δχ²_SPT is monotone increasing for A_CB ≥ 0 (the SPT posterior peaks at negative A_CB). Every model can reach A_CB → 0 (small H_inf), so the joint best fit has A_CB = 0 and SPT adds nothing to Δχ² at the best fit. Δχ²_SPT at each model's largest A_CB is listed as the worst case.

Run (from the repo root; about 2.5 min on 1 CPU: validation 1 min, claim numbers 1.3 min, fits 10 s):
```
.venv/Scripts/python tools/pin.py .venv/Scripts/python -m src.reproduce            # all steps, run.log
.venv/Scripts/python tools/pin.py .venv/Scripts/python -m src.reproduce --skip-validation
.venv/Scripts/python tools/pin.py .venv/Scripts/python work/20261120-014-data-reproduce-fit/fit_candidates.py
```

## Verdict
- `src.reproduce` regenerates every CLAIMS.md number from data/ in about 2.5 min on 1 CPU.
  - All match except EC-04's "~10¹²⁰", which is 4.3×10¹²⁰ (rounding wording).
  - The EC-03 QCD-mass numbers still reproduce from 008 but are superseded (skeptic 011).
- Fits: every candidate mechanism is an ALP at the level of the β data. They differ only in where β is capped.
  - With the cited Planck 2018 caps at 10⁻³² eV (6.9%; 2.7% with BOSS), EC-03' (hand-set g) pays Δχ² = 0.5-2.4 on ACT alone and 3.2-8.0 on ACT+WMAP+Planck relative to a free ALP.
  - The 12% case that fits ACT is excluded by Planck 2018 at 10⁻³² eV. No bound exists at 5-8×10⁻³³ eV, so this is not a strict exclusion at the best-fit mass.
  - KK-02 k = 1 is cheap on ACT (0.01) and pays 0.9 on the combination. k = 2 has no penalty.
  - No model is preferred over a free-β ALP by AIC or BIC. All tie at best.
  - Larger B₁₀ for bounded models reflects their narrower priors, not better fits.
  - SPT A_CB does not discriminate between them.

## Open issues
- EC-02, EC-04, EC-05 numbers are parsed from printed output that is already rounded (e.g. 7.47×10⁻³⁰, 28.5, 1.7×10⁸). A change in the 3rd significant figure would go unseen. The scripts would need to return values to fix this, which means editing 007 scripts (not allowed here).
- EC-03' β_max is recomputed unrounded with 3 lines mirroring `variants.main`. If `variants.main` changes its formula, the assert on m_best catches only a change in the location of the maximum, not one in its value.
- The prior dependence of B₁₀ is large. The generic ALP gets B₁₀ = 6.3 with [-1°, 1°]. KK-02 k = 1 and EC-03' 12% get about 14 because their priors are narrower (±0.21°). These are not evidence that the specific models are preferred over an ALP. A bounded model's prior is fixed by its physics; the ALP prior width is a choice.
- BIC with a compressed β (n = 1) has no penalty. The ACT β comes from hundreds of EB/TB bandpowers, so a "real" n would add k ln n ≈ 5-6 per parameter. That is not computable from the compressed likelihood.
- The SPT part is uninformative for these models: EC-03' predicts A_CB ~ 10⁻¹⁶, and KK-02's envelope (1.3×10⁻⁵ for k = 1) costs Δχ² ≈ 0.4 at most. Since all models can set A_CB = 0, SPT does not discriminate among them.
- `act_wmap_planck` is the published inverse-variance combination. It assumes independence and uses symmetrised EK22 errors (010 open issue).
