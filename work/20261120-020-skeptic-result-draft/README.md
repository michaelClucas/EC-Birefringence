## Verdict
- **4D track as Result B: no.** It survives only for spin-sourced (algebraic) EC torsion. Fix item 1 by computing the unsourced-torsion class or by restricting the scope and saying a Result C may exist there. The KK-05 dispute does not affect this track.
- **KK track: yes with fixes, but not as written.** Under either EDM outcome the draft's own rule gives Result C (item 2). It becomes a clean Result B under both outcomes if the KK charge-to-mass argument (item 3) is written up and the photon-mixing loophole is closed. Otherwise it is Result C with KK-05's costs, the KK-charge mechanism first.
- Items 4-12 are wording, scope and bookkeeping fixes; no number in CLAIMS.md failed to reproduce.
